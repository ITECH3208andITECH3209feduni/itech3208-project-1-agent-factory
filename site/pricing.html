Open Source & Deployment Specs

Deployment Tiers & Resource Models

Agent Factory is an academic open-source research initiative. There are no paywalls, no trial signups, and no recurring subscriptions. Review the deployment profiles below based on your lab or infrastructure scale.

Student & Researcher

Local Development

$0 / Open Source

Ideal for individual researchers, coursework, and local evaluations running on a single laptop or workstation.

  • Single-process FastAPI + SQLite WAL backend
  • Local ChromaDB vector database
  • Full Literature Review & arXiv/PubMed integrations
  • Local web dashboard & chat interface
  • Standard mock Twilio mode for testing

Clone from GitHub and run locally with Python 3.12+ or Docker.

Recommended for Labs
Research Group

Academic Lab Cluster

Self-Hosted / Multi-User

Designed for university research groups and faculty labs requiring persistent knowledge bases and live phone reception.

  • All Local Development features included
  • Live Twilio Voice & SMS phone numbers
  • Google Calendar service-account appointment sync
  • Multi-user role-based authentication
  • Delivery status tracking & email bounce handler
  • Automated analytics & operational KPI charts

Deployable via docker-compose on campus servers or AWS/GCP instances.

Campus Infrastructure

Campus-Wide Production

Institutional / Scaled

High-throughput deployment for university-wide student inquiry routing and automated faculty literature reviews.

  • Containerized agent pools with Linux VM isolation
  • Persistent PostgreSQL or distributed SQLite storage
  • Full FedUni RAG crawl corpus (1,200+ crawled campus pages)
  • Automated GitHub Actions CI/CD deployment pipelines
  • Custom branding passes and theme customization
  • Enterprise SLA monitoring and webhook telemetry

Designed for Federation University IT infrastructure specifications.
